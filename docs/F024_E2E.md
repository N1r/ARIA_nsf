# F024 real-audio acceptance workflow

This is the mechanical acceptance test used while building PhonLab-DDSP. It uses
the existing five-minute F024 budget subset (213 utterances) and never modifies
the source corpus.

## Inputs and fixed parameters

- Source: `/zfsstore/user/dingyr/data1/speech_synthesis/f024_budget/budget_5min`
- Audio: 16 kHz mono WAV
- F0: existing 5 ms `.pv` sidecars (`sidecar-pv` in the manifest)
- Split seed: 42
- Splits: 198 train / 11 validation / 4 test
- Model: GOLF 16 kHz
- Smoke training: batch size 2, one optimizer step

## Rebuild

```bash
source scripts/project_env.sh
./scripts/setup_project_env.sh

.venv/bin/phonlab prepare \
  /zfsstore/user/dingyr/data1/speech_synthesis/f024_budget/budget_5min \
  artifacts/f024_smoke/dataset \
  --sample-rate 16000 --f0-method sidecar \
  --validation-ratio 0.05 --test-ratio 0.02 --seed 42

.venv/bin/phonlab inspect artifacts/f024_smoke/dataset
.venv/bin/phonlab init-experiment \
  artifacts/f024_smoke/dataset artifacts/f024_smoke/experiment \
  --model golf --batch-size 2 --max-steps 1 --workers 0

sbatch slurm/f024_e2e_smoke.slurm
```

The Slurm job requests one available GPU, validates the project-local cache policy, runs tests, trains one
step, checks `last.ckpt`, reconstructs all four held-out files, and builds
`artifacts/f024_smoke/comparison.html`.

The final predicate is:

```bash
python3.11 tools/check_f024_e2e.py artifacts/f024_smoke
```

One optimizer step verifies wiring and numerical execution; it does not establish
model quality or convergence.

## ARIA-GOLF F1/F2/tilt acceptance

The ARIA path uses 400 training steps rather than the one-step wiring smoke.  A
one-step checkpoint was tested first, but its untrained output peaked at
473.24 before PCM clipping, so it was rejected rather than hidden with output
gain.  The reproducible Slurm entry point is:

```bash
mkdir -p artifacts/f024_aria_smoke
sbatch slurm/f024_aria_e2e_smoke.slurm
```

The accepted run used the checkpoint with the lowest validation loss and six
isolated conditions: F1 scale 0.9/1.1, F2 scale 0.9/1.1, and tilt alpha delta
-0.1/+0.1.  Re-run the CPU-only artifact predicate with:

```bash
make verify-aria
```

The predicate checks the checkpoint SHA-256, experiment and dataset identity,
runtime capabilities, decoder-hook calls, complete WAV sets, zero clipping,
and pairwise-distinct up/down audio.  It does not claim that an independent
formant tracker will measure an exact ten-percent change on every frame.
